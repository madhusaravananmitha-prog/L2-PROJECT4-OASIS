# 📱 Unveiling the Android App Market: Analyzing Google Play Store Data

## 📌 Project Overview

This project focuses on analyzing Google Play Store data to gain valuable insights into the Android app market. The analysis involves cleaning and preprocessing app data, exploring app categories, examining ratings and popularity trends, analyzing pricing strategies, and performing sentiment analysis on user reviews.

Through data visualization and exploratory data analysis (EDA), this project helps uncover patterns in app performance, user preferences, and market dynamics within the Google Play ecosystem.

---

## 🎯 Objective

* Clean and preprocess Google Play Store data.
* Explore app distribution across categories.
* Analyze app ratings, installs, reviews, size, and pricing trends.
* Perform sentiment analysis on user reviews.
* Create meaningful visualizations to understand market behavior.
* Extract actionable insights from app and user review data.

---

## 📂 Dataset

**Dataset Name:** Android App Market on Google Play

**Source:** Kaggle Dataset

Dataset Files:

* Google Play Store Apps Data
* Google Play Store User Reviews Data

* App Name
* Category
* Rating
* Reviews
* Size
* Installs

* Price

## 📊 Key Insights

### App Category Distribution

* Categories such as Family, Games, and Tools contain the highest number of applications.
* Certain niche categories have fewer apps but higher average ratings.

### Ratings Analysis

* Most applications maintain ratings between 4.0 and 4.5.
* Highly rated apps generally receive a larger number of installs and reviews.

### Popularity Analysis

* Communication, Social, and Entertainment apps tend to achieve the highest installation counts.
* Popular apps often receive substantial user engagement through reviews.

### Pricing Trends

* The majority of applications on the Google Play Store are free.
* Paid applications represent a small portion of the marketplace.
* Pricing varies significantly across categories.

### Sentiment Analysis

* Most user reviews are positive.
* Negative reviews frequently mention bugs, crashes, and performance issues.
* Positive reviews often highlight usability, functionality, and user experience.
